# I had nothing, I had, I have nothing again — Inspired by Damyan Damyanov

A Ruby poem inspired by the Bulgarian poet Damyan Damyanov. Each run shuffles four experiences. What I have eventually disappears. What I give can remain in the world beyond my ownership.

[Read the Ruby](a_life_in_ruby.rb)

From the repository root, run:

```sh
ruby a-life-in-ruby/a_life_in_ruby.rb
```
